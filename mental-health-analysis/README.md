# Mental Health in the Workplace Analysis

## Overview

This project analyzes mental health survey data to understand how workplace and demographic factors influence treatment-seeking behavior.

## Tools Used

* Python (Pandas, NumPy)
* Data Visualization (Matplotlib, Seaborn)
* Jupyter Notebook

## Key Insights

* Many individuals report seeking mental health treatment
* Workplace interference is strongly associated with treatment behavior
* Access to employer benefits may influence treatment decisions

## Interactive Tableau Dashboard

To extend the original Python analysis, I developed an interactive Tableau dashboard that allows users to explore mental health treatment-seeking patterns across demographic and workplace factors.

The dashboard includes:

* Overall survey participation and treatment-seeking KPIs
* Treatment-seeking by gender
* Employer mental health benefits and treatment seeking
* Work interference and treatment seeking
* Interactive country filtering

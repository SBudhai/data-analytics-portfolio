### 📚 Queens Public Library Network Analysis

Explores the geographic distribution and community reach of Queens Public Library locations using NYC Open Data.

The project combines Python-based data preparation with an interactive Tableau dashboard to examine how **66 library locations** are distributed across **53 ZIP codes, 14 community boards, and 41 neighborhoods** throughout Queens.

The dashboard includes KPI cards, an interactive geographic map, a neighborhood treemap, a community board visualization, branch-level tooltips, and cross-filtering between visualizations.

**Skills demonstrated:**  
Python • Pandas • Tableau • NYC Open Data • Geographic Analysis • Interactive Dashboards • Data Visualization • Data Storytelling

---

### 🌍 Global Economic Analysis

Analyzes international economic data covering **220 countries and areas from 1970–2021** to explore global patterns in GDP, GDP per capita, population, and international trade.

Python was used to clean and transform more than **10,000 records**, create additional economic indicators such as trade balance and year-over-year GDP change, and prepare the data for visualization.

An interactive Tableau dashboard provides multiple perspectives on the data through a global GDP map, time-series analysis, economic comparison scatter plot, trade balance visualization, and financial KPI cards.

**Skills demonstrated:**  
Python • Pandas • Tableau • Economic Data Analysis • Feature Engineering • Time-Series Visualization • Geographic Visualization • Interactive Dashboards
